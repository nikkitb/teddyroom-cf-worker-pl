# Consent & GTM Injector Worker

Cloudflare Worker example used to inject consent defaults, Cookiebot and Google Tag Manager into HTML responses.

## Features

- HTML response modification
- Cookiebot injection
- Google Consent Mode defaults
- GTM head snippet injection
- GTM noscript fallback
- duplicate injection cleanup

## Use Cases

- e-commerce tracking setup
- consent-first analytics implementation
- limited backend/template access
- multi-domain tracking support
- controlled GTM deployment from the edge

## Stack

- Cloudflare Workers
- JavaScript
- Google Tag Manager
- Google Consent Mode
- Cookiebot

## Notes

Generalized example inspired by real-world e-commerce analytics and consent management scenarios.

# Meta Feed Proxy Worker

Cloudflare Worker example used to proxy XML product feeds for advertising and marketplace environments.

## Features
- XML feed proxy handling
- custom response headers
- MetaBot user-agent forwarding
- cache-control handling
- lightweight request routing

## Use Cases
- product feed proxying
- marketplace feed delivery
- advertising feed handling
- e-commerce infrastructure support

## Stack
- Cloudflare Workers
- JavaScript

## Notes
Generalized example inspired by real-world e-commerce feed and tracking support scenarios.

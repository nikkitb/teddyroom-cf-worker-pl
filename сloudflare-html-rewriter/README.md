# Cloudflare Tracking Injection Worker

Cloudflare Worker used to control tracking infrastructure at the edge by removing legacy tracking snippets and injecting a managed consent and analytics setup.

## Features

- HTML response rewriting
- Legacy tracking cleanup
- Cookiebot injection
- Consent Mode initialization
- GTM injection
- Duplicate script prevention
- Multi-domain support

## Use Cases

- E-commerce analytics governance
- Tracking migration projects
- Multi-market storefronts
- Platforms with limited template access
- Server-side tracking preparation

## Stack

- Cloudflare Workers
- JavaScript
- Google Tag Manager
- Cookiebot
- Google Consent Mode
